# Sample Files

These fictional files demonstrate the three access-control
policies implemented in AegisVault.

| File | Recommended Policy | Role |
|---|---|---|
| 01_private_financial_record.txt | PRIVATE | N/A |
| 02_public_read_announcement.txt | PUBLIC_READ | N/A |
| 03_role_restricted_viewer_guide.txt | ROLE_RESTRICTED | VIEWER |

## Usage

1. Sign in as an administrator.
2. Open Storage objects.
3. Upload each sample file with its corresponding policy.
4. Create a VIEWER account.
5. Test authorized and unauthorized access requests.
6. Run the independent verification matrix.

All sample data is fictional and intended for demonstration.
